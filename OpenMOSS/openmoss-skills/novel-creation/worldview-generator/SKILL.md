# SKILL.md - 世界观生成Skill

## 概述
AI小说世界观生成器，帮助创建完整、独特的小说世界设定。

## 输入
- **genre**: 小说类型（玄幻/科幻/都市/历史/悬疑/武侠等）
- **tone**: 整体基调（严肃/轻松/黑暗/光明/幽默等）
- **scope**: 世界规模（微观/中等/宏观）
- **core_theme**: 核心主题（可选，如"爱与牺牲"）

## 输出
完整的世界观文档，包含：
- 世界背景与设定
- 法则与规则
- 势力分布
- 历史脉络
- 地理环境
- 特色元素

## 使用示例
```
genre: 玄幻
tone: 热血
scope: 宏观
core_theme: 逆天改命
```

## 调用方式
```json
{
  "skill": "worldview-generator",
  "params": {
    "genre": "玄幻",
    "tone": "热血",
    "scope": "宏观",
    "core_theme": "逆天改命"
  }
}
```
