# SKILL.md - 润色修改Skill

## 概述
AI小说润色工具，提升文笔质量，优化阅读体验。

## 输入
- **text**: 待润色的文本
- **focus_area**: 重点修改方向（可选）：
  - 语言流畅度
  - 人物刻画
  - 场景描写
  - 对话优化
  - 情感表达
  - 节奏调整
- **style**: 目标文风（可选）：
  - 简洁干练
  - 华丽辞藻
  - 幽默风趣
  - 深沉内敛
- **intensity**: 修改强度（轻度/中度/深度）

## 输出
润色后的文本，以及修改说明：
- 具体修改内容
- 修改理由
- 优化建议

## 使用示例
```
text: [待润色的段落]
focus_area: 语言流畅度
intensity: 中度
```

## 调用方式
```json
{
  "skill": "polish-editor",
  "params": {
    "text": "待润色的文本内容...",
    "focus_area": "语言流畅度",
    "intensity": "中度"
  }
}
```

## 质量标准
- 保持原文的核心意思
- 提升阅读流畅度
- 增强画面感
- 优化情感表达
- 避免过度修改
