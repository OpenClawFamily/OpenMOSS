# AI小说创作Skill体系设计文档

## 一、概述

本文档描述AI小说创作助手Skill体系的设计方案，旨在创建一套完整、系统化的AI辅助小说创作工具。

## 二、Skill体系架构

### 2.1 核心模块

| Skill名称 | 功能描述 | 优先级 |
|-----------|----------|--------|
| worldview-generator | 世界观生成 | 高 |
| character-generator | 角色生成 | 高 |
| plot-generator | 情节生成 | 高 |
| polish-editor | 润色修改 | 高 |

### 2.2 模块关系

```
世界观生成 → 角色生成 → 情节生成 → 撰写正文 → 润色修改
     ↑                                    ↓
     └────────── 反馈循环 ←───────────────┘
```

## 三、详细设计

### 3.1 世界观生成Skill (worldview-generator)

**功能**：根据给定参数生成完整的小说世界设定

**输入参数**：
- `genre`: 小说类型（玄幻/科幻/都市/历史/悬疑/武侠）
- `tone`: 整体基调（严肃/轻松/黑暗/光明/幽默）
- `scope`: 世界规模（微观/中等/宏观）
- `core_theme`: 核心主题（可选）

**输出内容**：
1. 世界背景与设定
2. 法则与规则（修炼体系、科技水平等）
3. 势力分布（门派、国家、组织等）
4. 历史脉络
5. 地理环境
6. 特色元素

### 3.2 角色生成Skill (character-generator)

**功能**：创建有深度、有特色的故事人物

**输入参数**：
- `role_type`: 角色类型（主角/反派/配角/导师/酱油）
- `genre`: 小说类型
- `worldview`: 已有的世界观设定（可选）
- `character_arc`: 角色成长弧线（可选）
- `relation_to_main`: 与主角关系（可选）

**输出内容**：
1. 基础信息（姓名、年龄、外貌特征）
2. 性格特点（MBTI或自定义性格描述）
3. 背景故事（出身、经历）
4. 能力/技能（实力等级、技能树）
5. 动机与目标（欲望、恐惧）
6. 成长弧线
7. 标志性特征（口头禅、习惯动作）

### 3.3 情节生成Skill (plot-generator)

**功能**：设计引人入胜的故事线和情节发展

**输入参数**：
- `plot_type`: 情节类型（升级/复仇/探案/恋爱/战争/冒险）
- `pacing`: 节奏（快节奏/中等/慢热）
- `chapter_count`: 预计章节数
- `worldview`: 世界观设定
- `characters`: 主要角色信息
- `twist_needed`: 是否需要反转（是/否/随机）

**输出内容**：
1. 主线剧情（核心冲突与发展）
2. 支线剧情（辅助情节）
3. 关键转折点（列出具体章节）
4. 高潮设计（情感高潮、情节高潮）
5. 悬念设置
6. 章节概要（每章一句话）

### 3.4 润色修改Skill (polish-editor)

**功能**：提升文笔质量，优化阅读体验

**输入参数**：
- `text`: 待润色的文本
- `focus_area`: 重点修改方向
  - 语言流畅度
  - 人物刻画
  - 场景描写
  - 对话优化
  - 情感表达
  - 节奏调整
- `style`: 目标文风
  - 简洁干练
  - 华丽辞藻
  - 幽默风趣
  - 深沉内敛
- `intensity`: 修改强度（轻度/中度/深度）

**输出内容**：
1. 润色后的完整文本
2. 修改说明（具体修改内容+理由）
3. 优化建议

## 四、使用流程

### 第一阶段：世界观设定
1. 调用 `worldview-generator` 生成世界背景
2. 根据需要调整和细化

### 第二阶段：角色创建
1. 调用 `character-generator` 创建主角
2. 调用 `character-generator` 创建重要配角
3. 调用 `character-generator` 创建反派

### 第三阶段：情节规划
1. 调用 `plot-generator` 生成大纲
2. 根据需要调整章节安排

### 第四阶段：内容创作
1. 基于大纲撰写正文
2. 过程中可随时调用 `character-generator` 补充角色细节

### 第五阶段：润色完善
1. 调用 `polish-editor` 进行整体润色
2. 可针对不同章节多次调用

## 五、质量标准

- **完整性**：覆盖小说创作的各个环节
- **一致性**：各Skill输出内容相互协调
- **可调性**：支持参数调整和人工干预
- **高质量**：产出符合出版/发布标准的内容
